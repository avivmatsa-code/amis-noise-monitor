# AMIS Noise Monitor

מערכת אינטרנטית מקומית לניטור עוצמת רעש משוערת באמצעות המיקרופון ולהתרעה
בעת חריגה מסף מוגדר. עיבוד השמע מתבצע בדפדפן בלבד ואינו נשלח לשרת.

## דיוק המדידה

הדפדפן מספק אות דיגיטלי יחסי (`dBFS`). ערך ה־dB המוצג הוא אומדן המבוסס על
היסט כיול שהמשתמש יכול לשנות. אין להשתמש במערכת כתחליף למד רעש מקצועי או
לצורך החלטות רפואיות ובטיחותיות.

## עיצוב

הממשק מבוסס על AMIS Clear UI v0.2 ותומך בעברית RTL, באנגלית LTR ובשש ערכות
הצבע התקניות.

מקור התקן: https://github.com/avivmatsa-code/amis-clear-ui

## הפעלה ובנייה

```bash
pnpm install
pnpm run dev
pnpm run build
```

גישה למיקרופון דורשת HTTPS או סביבת `localhost`.
